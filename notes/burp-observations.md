# Burp Suite - Initial Observations

## 1. Project Overview

This activity is part of my Web Application Vulnerability Assessment and Penetration Testing (VAPT) project. I used Burp Suite to inspect HTTP traffic generated by the OWASP Juice Shop application running locally on my Kali Linux system.

## 2. Testing Environment

- **Target Application:** OWASP Juice Shop
- **Target URL:** http://127.0.0.1:3000
- **Operating System:** Kali Linux
- **Testing Tool:** Burp Suite Community Edition
- **Testing Type:** Initial HTTP Request and Response Analysis
- **Environment:** Local practice lab

## 3. Request Details

- **Request Method:** GET
- **Request Path:** /
- **HTTP Version:** HTTP/1.1
- **Host:** 127.0.0.1:3000
- **Response Status:** 200 OK
- **Content-Type:** text/html; charset=UTF-8

## 4. Response Header Observations

The following headers were observed in the HTTP response:

- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: SAMEORIGIN`
- `Access-Control-Allow-Origin: *`
- `Cache-Control: public, max-age=0`
- `Content-Type: text/html; charset=UTF-8`
- `Feature-Policy: payment 'self'`

The response also included an `X-Recruiting` header with the value `/#/jobs`.

## 5. Initial Analysis

The server returned HTTP 200 OK, indicating that the requested page was served successfully.

The `X-Content-Type-Options: nosniff` header helps prevent browsers from interpreting content as a different MIME type.

The `X-Frame-Options: SAMEORIGIN` header restricts framing to the same origin in browsers that enforce this header.

The `Access-Control-Allow-Origin: *` header permits cross-origin access to resources covered by this response. Its security impact must be evaluated alongside the relevant endpoints, resource sensitivity, and other CORS settings.

The `Cache-Control: public, max-age=0` header allows caching but indicates that the response is immediately stale and should be revalidated before reuse.

These observations alone do not confirm a vulnerability. Further testing is required before assigning a finding or severity.

## 6. Conclusion

The initial HTTP inspection was completed successfully using Burp Suite. The request method, response status, content type, and selected security-related headers were documented.

The next stage will involve examining application API requests and validating potential security issues within the authorized OWASP Juice Shop lab.
